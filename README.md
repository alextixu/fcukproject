# 台股局部高低點判斷(主軸)

判斷台股每一天 t 是不是 11 天窗口(t−5 ~ t+5)收盤的局部**高點**、**低點**,或**非極值**。只用 t 當天收盤以前的資料。

**方法(主軸):規則候選 → AE + OC-SVM**
1. 規則挑候選:t 收盤是最近 6 天最高 → 高點候選;最低 → 低點候選。其餘判非極值。
2. 高點、低點各一組模型,輸入是 t−5 ~ t 六根 K 線的 29 維特徵,經 AE(29 → 16)壓縮。
3. OC-SVM(nu 0.1)用相似樣本權重,只學真的高(低)點;候選落在範圍內才保留。

**資料:** TW200 剔除低波動股後 168 檔,2016 ~ 2026-09。
**驗證:** walk-forward,測哪一年就用前 4 年訓練,種子 42。

| 測試年 | macro-F1 | 低點找到 / 命中 | 高點找到 / 命中 | 高低點判反 |
|---|---|---|---|---|
| 2024 | 54.31% | 87.6% / 27.7% | 86.8% / 29.8% | 0 |
| 2025 | 53.42% | 83.3% / 28.2% | 82.2% / 27.8% | 0 |
| 2026(1–9 月) | 54.51% | 71.5% / 31.9% | 66.5% / 26.7% | 0 |

**回測:** 扣掉成本(一趟 0.585%)後,所有試過的只做多策略都虧損,也都輸給 0050 與等權買進持有。
- 30 種組合,2024–2025:最好 −6.56%;同期 0050 +102.02%。
- 前 3 檔持有 5 天:2024 / 2025 / 2026 分別 −16.52% / −44.02% / −17.62%。

所以主軸是**看盤時的輔助判斷,不是交易訊號**。

方法細節、結果、重現指令見 [`method_kline_peak/README.md`](method_kline_peak/README.md)。
