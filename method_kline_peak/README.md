# method_kline_peak — 11 日窗格中心高 / 低點三分類(頂 / 底 / 其他)

形態搜尋改成:找 11 日窗格中「第 6 天是 11 日最高點」的位置貼標,做頂 / 底 / 其他三分類。
本資料夾是**標籤貼法與可行性評估**(2026-10-18),不是交易系統。

## 標籤定義(評估後的建議版)

中心日 t = 窗格第 6 天,左右各 5 個交易日。

| 類別 | 條件(還原價) |
|---|---|
| 頂(1) | `H[t] > max(H[t-5..t-1])` 且 `H[t] ≥ max(H[t+1..t+5])` |
| 底(2) | `L[t] < min(L[t-5..t-1])` 且 `L[t] ≤ min(L[t+1..t+5])` |
| 其他(0) | 其餘 |
| 剔除 | 同一天既是頂又是底(大振幅包覆 K,TW50 共 29 筆)、左右不足 5 日的頭尾 |

- **決策時點 = t 收盤**:此時只看得到 t-5..t(左半 + 中心),右半就是標籤本身。
  特徵只能用 ≤ t 的資料(`causal_features`,自測會檢查);把整個 11 日窗格餵給模型等於把答案給模型。
- **切分**:train 2016–2022 / val 2023–2024 / test 2025-01 ~ 2026-09;每個交界前 5 個交易日 purge(右半窗格會跨進下一段)。

## 貼標細節的評估(TW50,2016 ~ 2026-09,129,067 個中心日)

| 細節 | 發現 | 建議 |
|---|---|---|
| 平盤(同價高點) | 兩側都嚴格 4.79%、同價算給第一次出現 6.14%、兩側都不嚴格 8.29%。兩側嚴格會讓同價雙頂整個消失:中華電 64%、金融股 32% 的頂不見,偏向低價低波動股 | **同價算給第一次出現**,每個頂恰好算一次 |
| 還原價浮點抖動 | yfinance 還原價 = 原價 × 還原因子,因子有 ~1e-7 抖動,會把原價上的平盤隨機拆開。兩側嚴格定義下 TW50 頂會多出 23%;首次出現定義下只多 0.5% | 比較時加相對容差 `TOL = 1e-5`(遠小於一檔跳動單位) |
| 除權息 | 加容差後,未還原與還原價的標籤只差 0.40% | 用還原價(影響小,但沒理由用未還原) |
| 幅度門檻(頂後須跌 ≥ 1 ATR) | 頂之後 5 日最低價中位數跌 4.4%(2.3 ATR),只有 2.1% 的頂跌不到 1 ATR;加門檻後頂只少 1.6% | 不需要,11 日窗格本身就濾掉了小波動 |
| 用收盤價取代高低價 | 頂 6.3% / 底 6.1%,與高低價口徑相近 | 依題目用高低價;收盤價口徑作對照(見下) |

類別比例:**頂 6.1% / 底 5.9% / 其他 88.0%**,逐年 5.9–6.5% 很穩;同檔相鄰兩個頂間隔中位數 14 個交易日。
虛無對照(每檔 K 棒順序打亂後重建價格)頂 6.0% / 底 6.0%:**頂底出現的頻率跟隨機序列一樣**。

## 可行性

### 1. 三分類其實只剩候選日上的二分類

t 收盤時已經知道左半條件:頂 ⊆ `left_top`(t 高於前 5 日高點,佔 23.0% 的日子)、底 ⊆ `left_bot`(18.0%)。
其餘約 59% 的日子在決策時就確定是「其他」。候選日內的基準率:P(頂 | left_top) = 26.6%(虛無 23.2%)、P(底 | left_bot) = 32.9%。

所以三分類的 accuracy 與 macro-F1 都會誤導:全猜「其他」accuracy 88%;
左半規則(left_top → 頂、left_bot → 底,不學任何東西)macro-F1 就有 **0.559**。
真正的指標是**候選日內的 AUC**(頂 vs 非頂 | left_top;底 vs 非底 | left_bot)。

### 2. 預測結果(TW50 test 2025-01 ~ 2026-09,95% CI 為 10 日區塊 bootstrap)

| 模型 | macro-F1 | 頂 \| 候選 AUC | 底 \| 候選 AUC |
|---|---|---|---|
| 左半規則(地板) | 0.559 | 0.50 | 0.50 |
| struct:LightGBM,只用左半突破幅度 | 0.560 | 0.509 | 0.493 |
| shape:struct + 6 根 K 棒形態 | 0.609 | 0.657 [0.636, 0.677] | 0.617 [0.592, 0.640] |
| knn 形態搜尋(6 根 K 棒,k = 50) | 0.493 | 0.681 [0.661, 0.699] | 0.644 [0.620, 0.670] |
| full:shape + 背景 / 大盤,3 seeds | 0.610 | 0.661 ± 0.001 | 0.623 ± 0.002 |
| **單一特徵**:收盤離當日高(低)點幾個 ATR | — | **0.711** | **0.676** |
| full,收盤價口徑 | 0.546 | 0.534 | 0.545 |

可預測的部分幾乎全來自單一特徵「收盤離當日高點多遠」,它單獨就贏過所有模型。
原因是機械性的:高低價口徑問的是「接下來 5 天會不會超過今天的最高價」。
上影線越長,超過它需要的漲幅越大,自然越常成為頂。
標籤改用收盤價定義後,這個效果消失,所有模型都掉到 AUC 0.49–0.55。

### 3. 經濟意義(t 收盤決策 → t+1 開盤進、t+5 收盤出,還原報酬)

| | 頂 | 底 | 其他 |
|---|---|---|---|
| 完美預知標籤(oracle) | −2.12% | +2.59% | +0.36% |
| 標籤確認後才進場(t+6 開 → t+10 收) | +0.38% | +0.30% | +0.34% |

- **預測的頂不會跌**:full 前 10% 頂 分數 +0.12% ~ +0.47%,候選日平均 +0.53%。
  依「收盤離高點」十分位排序,P(頂) 從 11% 單調升到 55%,報酬卻平的(+0.28% ~ +0.91%)。
  模型學到的是「高點不會被超過」,不是「價格會跌」。
- **底的報酬不是來自底標籤**:full 前 10% 底 分數 +1.7% ~ +2.2%(收盤價口徑 +3.8% ~ +4.0%)。
  但同樣在底候選日中,只按波動度(ATR14)取前 10% 就有 +3.99%;
  最能預測底標籤的特徵(收盤離低點多遠)只有 +0.63%。
  模型前 10% 中有 13–26% 落在 2025-04 關稅急跌後反彈。這是 2025–26 多頭裡高波動股反彈的效果,跟「預測對底」無關。
- **確認後無延續**:頂 / 底被確認後的下一個 5 日,報酬與「其他」一樣。

### 5. 使用者設計:第 5、6、7 天三日 K,只看最有把握的尾端(`tail_precision.py`)

目標改成「只要挑得出必漲 / 必跌,大部分判成不漲不跌也沒關係」。
所以在第 7 天收盤用三根 K(第 5、6、7 天)打分,只看分數最高的前 0.1% ~ 5%。
方向以第 8 天開盤 → 第 11 天收盤計;頂對應跌,底對應漲。
兩個測試段各自往前訓練:2022–23(含空頭)、2025-01 ~ 2026-09(多頭)。TW50 結果:

| | 2022–23 | 2025–26 |
|---|---|---|
| 完美預知「頂」之後真的跌 | 67.7%(平均 −1.14%) | 71.0%(−1.65%) |
| 完美預知「底」之後真的漲 | 73.6%(+1.45%) | 69.1%(+2.15%) |
| 「其他」之中 4 日漲跌在 ±1% 內 | 35.1% | 28.7% |
| LightGBM(三日 K 原始形態)前 0.1% 頂:標籤命中 / 真的跌 | 83% / 75%(n = 24,CI 55–88%) | 85% / 70%(n = 20,CI 48–85%) |
| 同上前 1% 頂:真的跌 | 56.6% | 54.0% |
| 三日漲最多的前 0.1%(naive):真的跌 / 報酬 | 62.5% / −2.53% | 65.0% / −2.22% |
| LightGBM(原系統 3 日 12 特徵)前 0.1% 底:真的漲 / 報酬 | 54.2% / +1.46% | 90.0% / +9.04%,但 20 筆中 14 筆是 2025-04-10 同一天 |
| 三日跌最多的前 0.1%(naive):真的漲 | 58.3% | 95.0%(同樣集中在 2025-04) |

- 頂底標籤是**形態**,不是**漲跌**。就算完美預知,頂之後也只有約 70% 真的跌、底之後約 70% 真的漲。
  「其他」也不等於不漲不跌,大部分是 ±1% 以外的趨勢行情。
- 模型最有把握的頂,標籤命中 83–85%,但真的跌只有 70–75%,而且只有約 20 筆。
  放寬到前 1% 就掉到 54–57%,接近丟銅板。報酬也不如「三日漲最多就放空」的 naive 反轉。
- 「必漲」的 90% 是單一天(2025-04-10 關稅暫緩隔天的全面反彈),換到 2022–23 只剩 37–54%。
- 沒有任何一個分數在兩個測試段都穩定達到「必」的水準。

### 6. 使用者設計:學第 1–5 天、第 6 天交易、看第 11 天比第 6 天高或低(`learn5_trade6.py`)

設計:
- 輸入:第 1–5 天五根 K。
- 交易:第 6 天開盤進場。
- 結果:r = 第 11 天收盤 / 第 6 天開盤 − 1。
- 標籤:漲 / 跌 / 不漲不跌。「不漲不跌」帶寬用兩種:固定 ±3%(`pct3`),或依各股波動的 ±σ20×√6(`sig1`)。

標籤比例(TW50 全期):
- `pct3`:漲 18.7% / 不漲不跌 66.7% / 跌 14.6%,逐年隨大盤變動大(2026 年漲 30%)。
- `sig1`:漲 16.4% / 不漲不跌 71.8% / 跌 11.9%,逐年穩定。

不挑股時,「第 11 天收盤高於第 6 天開盤」的比例:TW50 52–53%、TW200 50–51%。

以下為各分數前 0.5% 的「方向對」比例(括號內為平均報酬):

| 分數 | TW50 2022–23 | TW50 2025–26 | TW200 2022–23 | TW200 2025–26 |
|---|---|---|---|---|
| 漲:LightGBM(pct3) | 47.9% | 59.4%(+3.2%) | 51.4% | 62.8%(+5.0%) |
| 漲:kNN 形態搜尋(pct3) | 47.9% | 72.3%(+6.5%) | 52.6% | 69.4%(+6.4%) |
| 漲:LightGBM(sig1) | 49.6% | 49.5% | 54.9% | 60.0%(+3.6%) |
| 漲:第 1–5 天跌最多(反轉) | 43.8% | 72.3%(+7.4%) | 54.5% | 81.6%(+9.6%) |
| 跌:LightGBM(pct3) | 43.8% | 43.6%(實際 +3.8%) | 52.6% | 42.1%(實際 +3.4%) |
| 跌:LightGBM(sig1) | 47.9% | 40.6% | 46.8% | 43.0% |
| 跌:第 1–5 天漲最多(反轉) | 65.3% | 67.3% | 53.0% | 52.0% |

- **沒有「必跌」**:模型最有把握的「跌」在四格裡都在 40–53%,接近或低於丟銅板。
  固定 ±3% 帶寬下更糟,被判跌的平均反而漲 3–4%。
  原因是固定帶寬讓模型學到的是「波動大」而不是方向:高波動股同時更容易漲超過 3% 和跌超過 3%,多頭裡就是漲。
  「五天漲最多就會跌」在 TW50 兩段都有 65–67%,但換到 TW200 只剩 52–53%,不穩。
- **「必漲」只出現在 2025–26 多頭**:最高 70–82% 的漲,幾乎都是「第 1–5 天跌最多的股票」。
  不學任何東西的反轉排序就跟模型一樣好或更好,而且最多 27% 擠在同一天(2025-04 急跌後反彈)。
  同樣的做法在 2022–23 只有 44–55%。
- 學第 1–5 天的形態(LightGBM、kNN)沒有在兩個測試段都穩定贏過丟銅板或簡單反轉的尾端。

### 7. 換成原系統的 AE + OC-SVM(`ae_ocsvm.py`)

設定:
- 標籤:第 6 天是 11 日最高點 → 跌、最低點 → 漲、其餘 → 不漲不跌。
- 輸入:第 1–5 天五根 K。
- 模型:直接用 `method_kline/kline` 的 AE(潛在 4 維、60 輪)與 OC-SVM(nu = 0.1);漲、跌各訓練一組,漲方向優先。
- 原系統的形態搜尋條件(距離 ≤ 3 的相似樣本 ≥ 5 個且全部同方向)在這個標籤下留不下任何型態群:
  相似樣本中位數約 3,000 個,同類只佔約 11%。
  所以 AE 用該類全部訓練樣本;重要性權重改成「相似樣本中同類的比例」,當作 OC-SVM 的樣本權重。

測試期 2025-01 ~ 2026-09 的結果:

| | TW50 訓練 16–22 | TW50 訓練 20–23 | TW200 訓練 16–22 | TW200 訓練 20–23 |
|---|---|---|---|---|
| 原生判法 acc(OC-SVM 判在範圍內就出訊號) | 21.8% | 20.4% | 22.3% | 21.1% |
| 原生判法:判漲 / 判跌佔全部日子 | 55% / 30% | 55% / 32% | 55% / 30% | 61% / 25% |
| 原生判法:判漲命中 / 判跌命中 | 9.1% / 12.1% | 9.3% / 11.6% | 9.5% / 12.6% | 8.7% / 13.4% |
| 前 1% 判法 acc(全猜不漲不跌 87.6–87.8%) | 86.4% | 86.3% | 86.3% | 86.3% |
| 前 1% 判漲命中 / 判跌命中 | 15.3% / 14.9% | 10.4% / 13.9% | 17.6% / 17.9% | 15.7% / 17.6% |
| 對照:LightGBM 前 1% 判漲命中 / 判跌命中 | 20.3% / 23.3% | 20.8% / 18.8% | 23.3% / 28.2% | 23.3% / 29.4% |

- 原生判法下,OC-SVM 把 55–61% 的日子判漲、25–32% 判跌。
  漲、跌樣本在五根 K 的形態上跟其他日子沒有分開,OC-SVM 圈出的範圍幾乎蓋住整個特徵空間,acc 只剩 20–22%。
- 改成只判前 1%,命中 10–18%,比隨機(約 6%)好,但比 LightGBM 的 19–29% 差。

### 結論

- **標籤本身可以貼,定義清楚**。作為描述性的形態搜尋(標註歷史轉折、畫圖、當事件取樣)沒問題。
- **作為預測 / 交易訊號不可行**:
  1. 頂底頻率與隨機序列相同。
  2. 唯一可預測的部分是「收盤離高點的距離」這個機械效果,換收盤價口徑就消失。
  3. 預測對了也不賺。
  4. 確認後沒有延續。
- 與既有否證鏈一致,可列為第 11 維:「11 日中心轉折標籤 ✗」。

## 用法

```bash
python method_kline_peak/peak_labels.py                    # 自測:標籤(含同價雙頂)與特徵因果性
python method_kline_peak/feasibility.py --pool tw50        # 約 8 分鐘(4 核)
python method_kline_peak/diagnose.py --pool tw50           # 單一特徵十分位、月份集中度、單一因子對照
python method_kline_peak/feasibility.py --pool tw200 --variants hl close
python method_kline_peak/tail_precision.py --pool tw50     # 第 5–7 天三日 K,尾端命中率(約 1 分鐘)
python method_kline_peak/learn5_trade6.py --pool tw50      # 學第 1–5 天、第 6 天交易、看第 11 天(TW50 約 40 秒,TW200 約 4 分鐘)
```

資料:`common/cache/yf_2026`(還原 OHLCV)+ 大盤 `0050.TW`;需要 `pyarrow`、`scikit-learn`、`lightgbm`。

| 檔案 | 內容 |
|---|---|
| `peak_labels.py` | `label_window`(三種口徑 `hl` / `close` / `hl_atr`)、`causal_features`(51 欄,只用 ≤ t) |
| `feasibility.py` | 標籤統計、虛無對照、rule / struct / shape / full / knn 五種模型、候選日 AUC 與報酬 |
| `diagnose.py` | AUC 來源追查與底報酬的因子對照 |
| `tail_precision.py` | 使用者設計:第 5、6、7 天三日 K → 頂 / 底 / 其他,只評估高分尾端的漲跌命中率 |
| `learn5_trade6.py` | 使用者設計:第 1–5 天五根 K → 第 11 天收 vs 第 6 天開的漲 / 跌 / 不漲不跌,高分尾端命中率 |
| `confusion.py` | LightGBM 的 acc 與混淆矩陣(`--labels peak`:第 6 天最高 / 最低點;`--folds train2020-23`) |
| `ae_ocsvm.py` | 原系統 AE + OC-SVM 套到第 6 天最高 / 最低點標籤,acc 與混淆矩陣,與 LightGBM 對照(需要 torch) |
| `results/feasibility_<pool>.json`、`results/diagnose_<pool>.json` | 全部數字 |
