# method_kline_peak — 主軸:11 天窗口的局部高低點三分類

判斷台股每一天 t 是不是 11 天窗口(t−5 ~ t+5)的局部高點、低點,或都不是(非極值)。
方法 = **規則挑候選 → 高點、低點各一組 AE + OC-SVM 否決假候選**。只用 t 當天收盤以前的資料。

## 方法

### 1. 標籤
- t 收盤是 t−5 ~ t+5 這 11 天收盤的最高 → **高點**;最低 → **低點**;同價並列也算。
- 其餘(以及 11 天全部同價)→ **非極值**。
- 窗口不完整(資料頭尾 5 天)不貼標。標籤用到 t+5 的價格,所以只拿來訓練與對答案,不進特徵。

### 2. 規則候選
- t 收盤是 t−5 ~ t(最近 6 天)最高 → 高點候選;最低 → 低點候選。
- 不是候選的一律判非極值。真高低點幾乎都在候選內;唯一的例外是 t−5 ~ t 收盤全部同價。
- 判高點一定是高點候選、判低點一定是低點候選,所以**高點和低點不會互相判反**。

### 3. 29 維特徵(`mainline.shape_features`)
t−5 ~ t 六根 K 線,全部取 log、相對 t 收盤(與股價高低無關):

| 項目 | 天數 | 個數 |
|---|---|---|
| 開、高、低 ÷ t 收盤 | t−5 ~ t | 18 |
| 收盤 ÷ t 收盤 | t−5 ~ t−1(t 本身恆為 0) | 5 |
| 量 ÷ 到 t 為止的 10 日均量 | t−5 ~ t | 6 |

訓練期中位數補缺值 → 標準化 → 截在 ±5。

### 4. AE + OC-SVM(高點、低點各一組,`mainline.fit_class`)
- 只用訓練期的候選點;AE 與 OC-SVM 只學**真的**高點(或低點)。
- **AE**:一層線性編碼器 29 → 16,訓練 60 輪。
- **相似樣本權重**:每個真候選在標準化後的 29 維空間,找歐氏距離 ≤ 3.0 的其他候選,權重 = 其中同為真的比例(下限 0.001)。
- **OC-SVM**:在 16 維潛在空間訓練,RBF、gamma = scale、nu = 0.1,用上面的權重。
- 測試時,候選點落在 OC-SVM 範圍內 → 判高點(低點),否則改判非極值。OC-SVM 的 decision 值當作分數。

### 5. 資料與股票池
- 價格:yfinance 還原日線,2016-01-01 ~ 2026-09-11(快取在 `common/cache/yf_2026/`)。
- 股票池:TW200 候選清單中有資料的 216 檔,剔除低波動股 48 檔 → **168 檔**(`mainline.load_data(pool="tw200")`)。
  - 低波動股 = 2020 年起每日漲跌幅絕對值的中位數 < 0.725%。
- 所有股票一起訓練一組模型。

### 6. Walk-forward(`walkforward.run_year`)
- 測哪一年,就用前 4 年訓練:2024 ← 2020–2023;2025 ← 2021–2024;2026(1–9 月)← 2022–2025。
- 訓練期剔除最後 5 個交易日,因為它們的標籤會用到測試年的價格。
- 種子 42;訓練門檻 0%(所有真高低點都拿來訓練);對答案用原本的標籤。

## 結果

### 分類(`results/confusion_2024_2026_tw200.png` / `.json`)

| 測試年 | 測試天數 | macro-F1 | 低點找到率 | 低點命中率 | 高點找到率 | 高點命中率 | 高低點判反 |
|---|---|---|---|---|---|---|---|
| 2024 | 40,646 | **54.31%** | 87.6% | 27.7% | 86.8% | 29.8% | 0 |
| 2025 | 40,630 | **53.42%** | 83.3% | 28.2% | 82.2% | 27.8% | 0 |
| 2026(1–9 月) | 27,208 | **54.51%** | 71.5% | 31.9% | 66.5% | 26.7% | 0 |

- 找到率 = 真高(低)點被判對的比例。
- 命中率 = 判高(低)點裡真的是高(低)點的比例。
- 真高低點大多抓得到,但判出來的高低點約 7 成其實是非極值。

### 回測:只做多,扣成本後全部虧損

交易慣例:
- t 收盤出訊號 → t+1 開盤買。
- 成本一趟來回 0.585%(手續費 0.1425% × 2 + 證交稅 0.3%)。
- 起始 100 萬,每檔 = 前一天總資產 / K。
- 訊號多於空位時,分數高的優先。

**只做多前 3 檔、持有 5 天**(`backtest_top3.py`,`results/backtest_long_only_tw200.json`):

| 年 | 扣成本 | 沒扣成本 | 筆數 | 勝率 | 最大回撤 |
|---|---|---|---|---|---|
| 2024 | −16.52% | +10.58% | 144 | 45.8% | −27.6% |
| 2025 | −44.02% | −25.88% | 144 | 36.8% | −46.1% |
| 2026(1–9 月) | −17.62% | −0.10% | 99 | 40.4% | −23.1% |

**30 種策略組合,2024–2025 連續兩年**(`backtest_strategies.py`,`results/backtest_strategies_2024_2025.json`):
- 策略 A–F 變化的項目:持有天數、檔數、判高點出場、等確認、均線過濾、只取高分、8% 停損。
- **30 種扣成本後全部虧損。**

| 策略 | 扣成本 | 沒扣成本 | 最大回撤 |
|---|---|---|---|
| 最好:E 168 檔等權,判高點賣、判低點買回 | −6.56% | +11.26% | −28.8% |
| 第 2:D3 個股與 0050 都在 60 日線上 + 停損 | −10.12% | +15.98% | −27.1% |
| 最差:A 前 3 檔持有 5 天 | −53.64% | −18.66% | −58.8% |
| 對照:0050 買進持有 | +102.02% | | |
| 對照:168 檔等權買進持有 | +30.02% | | |

**結論:**
- 主軸能把大部分真高低點挑出來,而且高低點不會判反。
- 但判出的高低點多數不是真的;扣掉成本後,所有試過的交易方式都虧損,也都輸給買進持有。
- 所以主軸適合當**看盤時的輔助判斷**(這裡可能是局部高 / 低點),**不是可以直接下單的交易訊號**。

## 重現

在 repo 根目錄執行:

```bash
pip install -r requirements.txt
python -m pytest method_kline_peak/tests -q                                   # 測試(固定用 TW50),會重寫 tests/REPORT.md
python method_kline_peak/report/confusion_2024_2026.py --pool tw200           # 混淆矩陣 2024–2026
python method_kline_peak/backtest_top3.py --pool tw200                        # 只做多前 3 檔回測
python method_kline_peak/report/equity_curves.py method_kline_peak/results/backtest_long_only_tw200.json
python method_kline_peak/backtest_strategies.py                               # 30 種策略(2024–2025)+ 對照
python method_kline_peak/report/stock_outputs.py 8046.TW --years 2024         # 個股每天的判斷
python method_kline_peak/report/stock_outputs.py 1519.TW 3661.TW 2388.TW 3653.TW --years 2024 2025 2026
```

- `backtest_strategies.py` 與 `stock_outputs.py` 共用每日判斷快取 `results/.cache_strategy_signals/`(不進 git)。
- 每年的混淆矩陣會先和 `confusion_2024_2026_tw200.json` 核對。
- 曾試過把 29 維特徵換成原系統的 2 日 K 特徵(10 維):三年 macro-F1 54.29 / 53.63 / 54.28%,和 29 維差不到 0.3 個百分點,沒有採用。
