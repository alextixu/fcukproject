# method_kline_peak — 11 日窗格中心高 / 低點三分類(頂 / 底 / 其他)

形態搜尋改成:找 11 日窗格中「第 6 天是 11 日最高點」的位置貼標,做頂 / 底 / 其他三分類。
本資料夾是**標籤貼法與可行性評估**(2026-10-18),不是交易系統。

## 目前主軸(2026-10-18 起,`mainline.py`)

**論文標籤 + 論文規則框架 + 我們的 AE + OC-SVM 否決假候選**(TW50)

1. 標籤(郭念慈、李俊宏 2.1 節):t 日收盤為 t−5 ~ t+5 最高 → 高點、最低 → 低點,並列也算,其餘 → 非極值。
2. 規則挑候選:t 日收盤為 t−5 ~ t 最高 → 高點候選、最低 → 低點候選;非候選一律判非極值。這一步不會漏掉任何真高低點。
3. AE + OC-SVM(高點、低點各一組)只用訓練期的候選點訓練;測試時候選點落在範圍內才保留,否則改判非極值。
   輸入:t−5 ~ t 六根 K 的 29 個數字(開高低收 ÷ t 日收盤、量 ÷ 10 日均量;2026-10-19 起由 20 日改為 10 日,見下方「量的基準天數」)。
   編碼器:一層 29 → 16(線性,不先升維;2026-10-19 起,之前為原系統 29 → 58 → 8 → 4,見下方「編碼器結構」)。
   目前主軸(10 日、29 → 16,我們的切分,3 種子):macro-F1 53.33% ± 0.08(規則 53.54%);種子 42:acc 67.7%,判對真高點 70.6%、真低點 79.8%,判非極值 93.9% 正確,高低點互相判錯 0 次。
4. 評估:
   - 主要指標:macro-F1。
   - 對照:規則基準、隨機否決同樣數量。
   - 「macro-F1 − 規則」的 10 日區塊 bootstrap 95% CI。
   - 真 / 假候選的保留率:模型有用的話,真候選保留率要明顯高於假候選。

調參數只要換命令列參數,每次執行自動在 `results/experiments.csv` 追加一列,詳細結果在 `results/main_<tag>.json`:

```bash
python method_kline_peak/mainline.py --tag base                      # 基準
python method_kline_peak/mainline.py --tag win20 --window 20         # 輸入 K 棒數
python method_kline_peak/mainline.py --tag chip --extra chip         # 額外特徵組:pos / ctx / mkt / chip
python method_kline_peak/mainline.py --tag z16 --latent 16 --epochs 100 --nu 0.05 0.1 --gamma 0.1 --weight none --dist 4
```

### Stacking(老師建議:拿掉規則,兩模型的輸出再訓練第三個模型;`stacking.py`)

切分:A 2020–2022 訓練兩組 AE + OC-SVM(只學真高 / 真低點)→ B 2023 用兩模型的分數訓練元學習器 → C 2024 測試;每段之間剔除 5 個交易日。
基底模型同主軸(29 個特徵、量 ÷ 10 日均量、29 → 16、nu 0.1),但沒有規則:OC-SVM 對每一天都給分數。
程式結構(2026-11 重構):`BaseScorers`(基底層)、`MetaLearner`(元學習器)、`StackingSource`(`SignalSource` 實作,可放進逐年回測)。
重構前後同一組合的結果逐一相同(`tests/test_stacking.py`)。

測試 2024 的 macro-F1(3 種子平均;對照:規則 54.20%、主軸 54.09%、先驗隨機 32.91%):

|---|---|---|---|---|---|---|---|---|
| 兩個 OC-SVM 分數(老師的版本) | 48.84% | 48.84% | 48.85% | 48.31% | 48.53% | 47.18% | 48.15% | 48.12% |

- 線性回歸、Ridge / Lasso / Elastic Net 回歸、多項式回歸輸出連續數字,不能直接做三分類,所以只取它們的正則化與多項式特徵,放進多類別邏輯迴歸。

做法:
- 真候選、假候選各訓練一組 AE + OC-SVM(六根 K、nu 0.1)。
- 分數 = 像真的程度 − 像假的程度,有兩種量法:
  - `ocsvm`:兩個 OC-SVM decision 在各自訓練集中的百分位數相減。
  - `recon`:假候選 AE 的重建誤差 − 真候選 AE 的重建誤差。
- 保留規則:分數 > 0,或只留分數最高的 90 / 70 / 50 / 30%。
- 每組都與「隨機保留同樣數量」對照。

| 我們的切分(規則 53.54%) | macro-F1(隨機保留) | 差 [95% CI] | 保留率 真 / 假(高點;低點) | 低點做多 勝率 / 扣成本後 |
|---|---|---|---|---|
| 規則全部候選 | 53.54% | — | 100 / 100%;100 / 100% | 54.3% / +0.28% |
| ocsvm 分數 > 0 | 51.93%(51.81%) | −1.61 [−2.47, −0.79] | 48 / 47%;48 / 48% | 55.1% / +0.44% |
| ocsvm 留 70% | 53.85%(53.46%) | +0.31 [−0.25, +0.84] | 70 / 70%;71 / 69% | 55.2% / +0.50% |
| ocsvm 留 50% | 52.26%(52.05%) | −1.28 [−2.13, −0.41] | 51 / 50%;50 / 50% | 55.3% / +0.51% |
| recon 留 90% | 54.04%(53.73%) | +0.50 [+0.17, +0.82] | 90 / 90%;91 / 90% | 54.0% / +0.16% |
| recon 留 50% | 52.50%(52.09%) | −1.04 [−2.07, −0.20] | 50 / 50%;52 / 49% | 53.8% / +0.18% |

(論文切分結果相同,完整 20 組見 `results/experiments.csv`、`results/main_contrast.json`。)

- 加上假候選後,真 / 假候選的保留率還是一樣(每組差距 ≤ 3 點),保留下來的命中率不變(高點約 25–27%、低點約 29–33%),交易勝率也與全部候選相同。
- 「留 90%」比規則多 0.3–0.7 點,CI 不含 0,但隨機刪掉 10% 也一樣多(隨機 53.73% vs 模型 54.04%)。
  這是 macro-F1 本身的性質(少判一些候選會讓非極值的 F1 上升),不是模型分辨出真假。
  而且 20 組裡挑最好的一組,本身就有多重比較的問題。
- 結論:就算讓 AE 同時學真假候選,六根 K 的形態裡仍然沒有分辨真假候選的資訊。

## 標籤定義(評估後的建議版)

中心日 t = 窗格第 6 天,左右各 5 個交易日。

| 類別 | 條件(還原價) |
|---|---|
| 頂(1) | `H[t] > max(H[t-5..t-1])` 且 `H[t] ≥ max(H[t+1..t+5])` |
| 底(2) | `L[t] < min(L[t-5..t-1])` 且 `L[t] ≤ min(L[t+1..t+5])` |
| 其他(0) | 其餘 |
| 剔除 | 同一天既是頂又是底(大振幅包覆 K,TW50 共 29 筆)、左右不足 5 日的頭尾 |

- **決策時點 = t 收盤**:此時只看得到 t-5..t(左半 + 中心),右半就是標籤本身。
  特徵只能用 ≤ t 的資料(`causal_features`,自測會檢查);把整個 11 日窗格餵給模型等於把答案給模型。
- **切分**:train 2016–2022 / val 2023–2024 / test 2025-01 ~ 2026-09;每個交界前 5 個交易日 purge(右半窗格會跨進下一段)。

## 可行性

### 1. 三分類其實只剩候選日上的二分類

t 收盤時已經知道左半條件:頂 ⊆ `left_top`(t 高於前 5 日高點,佔 23.0% 的日子)、底 ⊆ `left_bot`(18.0%)。
其餘約 59% 的日子在決策時就確定是「其他」。候選日內的基準率:P(頂 | left_top) = 26.6%(虛無 23.2%)、P(底 | left_bot) = 32.9%。

所以三分類的 accuracy 與 macro-F1 都會誤導:全猜「其他」accuracy 88%;
左半規則(left_top → 頂、left_bot → 底,不學任何東西)macro-F1 就有 **0.559**。
真正的指標是**候選日內的 AUC**(頂 vs 非頂 | left_top;底 vs 非底 | left_bot)。

### 2. 預測結果(TW50 test 2025-01 ~ 2026-09,95% CI 為 10 日區塊 bootstrap)

| 模型 | macro-F1 | 頂 \| 候選 AUC | 底 \| 候選 AUC |
|---|---|---|---|
| 左半規則(地板) | 0.559 | 0.50 | 0.50 |
| struct:LightGBM,只用左半突破幅度 | 0.560 | 0.509 | 0.493 |
| shape:struct + 6 根 K 棒形態 | 0.609 | 0.657 [0.636, 0.677] | 0.617 [0.592, 0.640] |
| knn 形態搜尋(6 根 K 棒,k = 50) | 0.493 | 0.681 [0.661, 0.699] | 0.644 [0.620, 0.670] |
| full:shape + 背景 / 大盤,3 seeds | 0.610 | 0.661 ± 0.001 | 0.623 ± 0.002 |
| **單一特徵**:收盤離當日高(低)點幾個 ATR | — | **0.711** | **0.676** |
| full,收盤價口徑 | 0.546 | 0.534 | 0.545 |

可預測的部分幾乎全來自單一特徵「收盤離當日高點多遠」,它單獨就贏過所有模型。
原因是機械性的:高低價口徑問的是「接下來 5 天會不會超過今天的最高價」。
上影線越長,超過它需要的漲幅越大,自然越常成為頂。
標籤改用收盤價定義後,這個效果消失,所有模型都掉到 AUC 0.49–0.55。

### 3. 經濟意義(t 收盤決策 → t+1 開盤進、t+5 收盤出,還原報酬)

| | 頂 | 底 | 其他 |
|---|---|---|---|
| 完美預知標籤(oracle) | −2.12% | +2.59% | +0.36% |
| 標籤確認後才進場(t+6 開 → t+10 收) | +0.38% | +0.30% | +0.34% |

- **預測的頂不會跌**:full 前 10% 頂 分數 +0.12% ~ +0.47%,候選日平均 +0.53%。
  依「收盤離高點」十分位排序,P(頂) 從 11% 單調升到 55%,報酬卻平的(+0.28% ~ +0.91%)。
  模型學到的是「高點不會被超過」,不是「價格會跌」。
- **底的報酬不是來自底標籤**:full 前 10% 底 分數 +1.7% ~ +2.2%(收盤價口徑 +3.8% ~ +4.0%)。
  但同樣在底候選日中,只按波動度(ATR14)取前 10% 就有 +3.99%;
  最能預測底標籤的特徵(收盤離低點多遠)只有 +0.63%。
  模型前 10% 中有 13–26% 落在 2025-04 關稅急跌後反彈。這是 2025–26 多頭裡高波動股反彈的效果,跟「預測對底」無關。
- **確認後無延續**:頂 / 底被確認後的下一個 5 日,報酬與「其他」一樣。

### 4. 使用者設計:第 5、6、7 天三日 K,只看最有把握的尾端(`tail_precision.py`)

目標改成「只要挑得出必漲 / 必跌,大部分判成不漲不跌也沒關係」。
所以在第 7 天收盤用三根 K(第 5、6、7 天)打分,只看分數最高的前 0.1% ~ 5%。

### 5. 使用者設計:學第 1–5 天、第 6 天交易、看第 11 天比第 6 天高或低(`learn5_trade6.py`)

設計:
- 輸入:第 1–5 天五根 K。
- 交易:第 6 天開盤進場。
- 結果:r = 第 11 天收盤 / 第 6 天開盤 − 1。
- 標籤:漲 / 跌 / 不漲不跌。「不漲不跌」帶寬用兩種:固定 ±3%(`pct3`),或依各股波動的 ±σ20×√6(`sig1`)。

標籤比例(TW50 全期):
- `pct3`:漲 18.7% / 不漲不跌 66.7% / 跌 14.6%,逐年隨大盤變動大(2026 年漲 30%)。
- `sig1`:漲 16.4% / 不漲不跌 71.8% / 跌 11.9%,逐年穩定。

不挑股時,「第 11 天收盤高於第 6 天開盤」的比例:52–53%。

以下為各分數前 0.5% 的「方向對」比例(括號內為平均報酬):

| 分數 | 2022–23 | 2025–26 |
|---|---|---|
| 漲:LightGBM(pct3) | 47.9% | 59.4%(+3.2%) |
| 漲:kNN 形態搜尋(pct3) | 47.9% | 72.3%(+6.5%) |
| 漲:LightGBM(sig1) | 49.6% | 49.5% |
| 漲:第 1–5 天跌最多(反轉) | 43.8% | 72.3%(+7.4%) |
| 跌:LightGBM(pct3) | 43.8% | 43.6%(實際 +3.8%) |
| 跌:LightGBM(sig1) | 47.9% | 40.6% |
| 跌:第 1–5 天漲最多(反轉) | 65.3% | 67.3% |

- **沒有「必跌」**:模型最有把握的「跌」都在 41–48%,低於丟銅板。
  固定 ±3% 帶寬下更糟,2025–26 被判跌的平均反而漲 3.8%。
  原因是固定帶寬讓模型學到的是「波動大」而不是方向:高波動股同時更容易漲超過 3% 和跌超過 3%,多頭裡就是漲。
  「五天漲最多就會跌」兩段都有 65–67%,是唯一兩段都站得住的,但離「必跌」還遠。
- **「必漲」只出現在 2025–26 多頭**:最高 72% 的漲,幾乎都是「第 1–5 天跌最多的股票」。
  不學任何東西的反轉排序就跟模型一樣好,而且有 23% 擠在同一天(2025-04 急跌後反彈)。
  同樣的做法在 2022–23 只有 44–48%。
- 學第 1–5 天的形態(LightGBM、kNN)沒有在兩個測試段都穩定贏過丟銅板或簡單反轉的尾端。

### 6. 換成原系統的 AE + OC-SVM(`ae_ocsvm.py`)

設定:
- 標籤:第 6 天是 11 日最高點 → 跌、最低點 → 漲、其餘 → 不漲不跌。
- 輸入:第 1–5 天五根 K。
- 模型:直接用 `method_kline/kline` 的 AE(潛在 4 維、60 輪)與 OC-SVM(nu = 0.1);漲、跌各訓練一組,漲方向優先。
- 原系統的形態搜尋條件(距離 ≤ 3 的相似樣本 ≥ 5 個且全部同方向)在這個標籤下留不下任何型態群:
  相似樣本中位數約 3,000 個,同類只佔約 11%。
  所以 AE 用該類全部訓練樣本;重要性權重改成「相似樣本中同類的比例」,當作 OC-SVM 的樣本權重。

兩種判法(同一個模型、同一批測試資料,只差在「怎麼把分數變成漲 / 跌 / 不漲不跌」;圖的上排 / 下排):
- **原生判法(上排)**:漲的 OC-SVM 判「在範圍內」就判漲,否則跌的 OC-SVM 判在範圍內就判跌,其餘不漲不跌。不限制出訊號的數量。
- **前 1% 判法(下排)**:用 OC-SVM 的分數(離範圍中心多近)排序,只有漲分數最高的前 1% 判漲、跌分數最高的前 1% 判跌,其餘全判不漲不跌。

測試期 2025-01 ~ 2026-09 的結果:

| | 訓練 2016–2022 | 訓練 2020–2023 |
|---|---|---|
| 原生判法 acc(OC-SVM 判在範圍內就出訊號) | 21.8% | 20.4% |
| 原生判法:判漲 / 判跌佔全部日子 | 55% / 30% | 55% / 32% |
| 原生判法:判漲命中 / 判跌命中 | 9.1% / 12.1% | 9.3% / 11.6% |
| 前 1% 判法 acc(全猜不漲不跌 87.8%) | 86.4% | 86.3% |
| 前 1% 判漲命中 / 判跌命中 | 15.3% / 14.9% | 10.4% / 13.9% |
| 對照:LightGBM 前 1% 判漲命中 / 判跌命中 | 20.3% / 23.3% | 20.8% / 18.8% |

- 原生判法下,OC-SVM 把 55% 的日子判漲、30–32% 判跌。
  漲、跌樣本在五根 K 的形態上跟其他日子沒有分開,OC-SVM 圈出的範圍幾乎蓋住整個特徵空間,acc 只剩 20–22%。
- 改成只判前 1%,命中 10–15%,比隨機(約 6%)好,但比 LightGBM 的 19–23% 差。

### 7. 論文標籤 + AE + OC-SVM(`paper_aeocsvm.py`)

標籤照郭念慈、李俊宏(逢甲資工)〈基於券商分點籌碼與雙分支圖神經網路之台股局部高低點預測〉2.1 節:
- t 日收盤為 t−5 ~ t+5 最高 → 高點,最低 → 低點,其餘 → 非極值。
- 並列最高(最低)的每一天都算;視窗內全部同價 → 非極值。
- t 日收盤後判斷。

輸入是 t−5 ~ t 六根 K(29 維),模型只用 AE + OC-SVM(不用 LightGBM),AE 種子 42 / 43 / 44 取平均。
用論文的規則重貼 TW50,比例是低點 / 非極值 / 高點 = 7.3 / 85.1 / 7.5%(論文訓練期)、8.0 / 85.0 / 7.0%(論文測試期),
與論文表 1 的 8.0 / 84.2 / 7.8、8.5 / 84.5 / 7.0 一致。

| 測試集 macro-F1(BalAcc) | 論文切分(訓練 2024-05 ~ 2025-08,測試 2025-10 ~ 2026-03) | 我們的切分(訓練 2020–2023,測試 2025-01 ~ 2026-09) | 論文表 2(12 檔) |
|---|---|---|---|
| 全猜非極值 | 約 30.6% | 約 30.7% | 30.53% |
| 規則基準(t 日為 t−5 ~ t 最高 / 最低) | **52.32%**(84.69%) | **53.54%**(85.27%) | **53.38%**(84.90%) |
| AE + OC-SVM(原系統判法) | 25.70 ± 1.42%(59.55%) | 29.06 ± 0.86%(61.31%) | — |
| 規則候選 + AE + OC-SVM | 51.96 ± 0.15%(75.77%) | 53.89 ± 0.13%(76.29%) | — |
| 論文 DualChartGNN3 | — | — | 54.81%(76.47%) |

- 規則基準在我們的資料上重現論文:52.3–53.5% 對 53.4%,BalAcc 84.7–85.3% 對 84.9%。
- AE + OC-SVM 單獨用(原系統判法)比全猜非極值還差:判低點 / 高點的日子佔 50% / 30%,精確率只有 14–17%。
- 「規則候選 + AE + OC-SVM」:OC-SVM 只決定規則挑出的候選點要不要保留。
  它剔除真低點與假低點的比例差不多(約 12%),高點也一樣(約 22%),所以精確率幾乎不變(低點 28–32%、高點 25–26%),macro-F1 與規則基準相差 ±0.4 點。
  論文的模型比規則多 1.43 點,同樣是在誤差範圍附近。

### 8. 論文的規則基準框架 + AE + OC-SVM 否決假候選(`paper_rule_aeocsvm.py`)

框架照論文:規則先挑候選(t 日收盤為 t−5 ~ t 最高 → 高點候選、最低 → 低點候選),非候選一律判非極值。
模型的唯一工作是否決「其後 5 日被超越」的假候選,這裡換成我們的 AE + OC-SVM。
- 與第 7 節的「規則候選 + AE + OC-SVM」不同,AE 與 OC-SVM **只用訓練期的候選點**訓練。
  重要性權重 = 相似候選點中同為真高(低)點的比例。
- nu 除了原系統的 0.1,另掃 0.2 / 0.3 / 0.5。
- 對照組:每類隨機否決同樣數量的候選點(20 次平均)。

候選點中真的比例(測試期):高點 25–27%、低點 29–32%,這就是規則基準的精確率。

| 測試集 | 論文切分 macro-F1(隨機否決) | 論文切分:真 / 假候選保留率(高點;低點) | 我們的切分 macro-F1(隨機否決) | 我們的切分:真 / 假候選保留率(高點;低點) |
|---|---|---|---|---|
| 規則基準 | 52.32% | 100 / 100%;100 / 100% | 53.54% | 100 / 100%;100 / 100% |
| + AE + OC-SVM nu 0.1 | 52.56%(52.64%) | 75 / 76%;92 / 91% | 53.69%(53.83%) | 75 / 75%;83 / 84% |
| nu 0.2 | 52.52%(52.69%) | 67 / 69%;86 / 85% | 53.17%(53.53%) | 65 / 65%;70 / 72% |
| nu 0.3 | 51.98%(52.40%) | 59 / 60%;75 / 77% | 52.39%(52.83%) | 56 / 57%;59 / 61% |
| nu 0.5 | 50.21%(51.18%) | 41 / 44%;52 / 55% | 50.75%(50.94%) | 41 / 42%;41 / 42% |

- 每一個 nu 下,AE + OC-SVM 保留真候選與假候選的比例都一樣(差距 ≤ 3 點),所以保留下來的命中率不變(高點約 25–26%、低點約 29–32%)。
  macro-F1 與「隨機否決同樣數量」相同或略差。
- nu 越大否決越多,acc 從 61–62% 升到 73–76%。但這只是多判非極值:真高低點被一起刪掉,macro-F1 反而下降。
- 結論:用六根 K 的形態,AE + OC-SVM 分不出「之後 5 天會被超越」的假候選。

### 9. 規則訊號直接拿來交易,勝率有沒有變高(`rule_trading.py`)

做法:t 日收盤為 t−5 ~ t 最低 → t+1 開盤買進;最高 → t+1 開盤放空;持有到 t+h 收盤。
TW50 全期 2016–2026,持有 5 天的結果:

| | 筆數 | 勝率 | 平均報酬 | 扣 0.42% 成本後 |
|---|---|---|---|---|
| 不挑時點,每天都做多 | 129,067 | 53.1% | +0.34% | −0.08% |
| **低點訊號做多** | 30,622 | **54.3%** | +0.29% | −0.13% |
| 　其中真低點(33%) | 10,041 | 90.0% | +2.80% | +2.38% |
| 　其中假候選(67%) | 20,581 | 36.9% | −0.93% | −1.35% |
| 不挑時點,每天都放空 | 129,067 | 46.2% | −0.34% | −0.76% |
| **高點訊號放空** | 37,599 | **46.9%** | −0.33% | −0.75% |
| 　其中真高點(27%) | 10,218 | 89.0% | +2.46% | +2.04% |
| 　其中假候選(73%) | 27,381 | 31.2% | −1.37% | −1.79% |

- 規則訊號的勝率只比不挑時點高 0.7–1.2 點,平均報酬一樣或更低;2022–23、2025–26 分開看、持有 1 / 3 天、不重疊持倉,結論都相同。
- 原因:真候選的勝率將近 90%,假候選只有 31–37%,而假候選佔了 2/3 到 3/4,加權平均回到和隨便哪一天進場差不多。
- 損益兩平的命中率(扣成本、持有 5 天):低點做多需要 1.35 / (2.38 + 1.35) ≈ **36%**(目前 33%);高點放空需要 1.79 / (2.04 + 1.79) ≈ **47%**(目前 27%)。
  模型要做的就是把候選的命中率拉過這條線,這也是主軸調整的目標。

### 結論

- **標籤本身可以貼,定義清楚**。作為描述性的形態搜尋(標註歷史轉折、畫圖、當事件取樣)沒問題。
- **作為預測 / 交易訊號不可行**:
  1. 頂底頻率與隨機序列相同。
  2. 唯一可預測的部分是「收盤離高點的距離」這個機械效果,換收盤價口徑就消失。
  3. 預測對了也不賺。
  4. 確認後沒有延續。
- 與既有否證鏈一致,可列為第 11 維:「11 日中心轉折標籤 ✗」。
