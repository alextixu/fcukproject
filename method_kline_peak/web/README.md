# K 線高低點判斷網頁(本機展示版)

每天收盤後判斷「台灣 50 哪些股票今天可能是 11 天高點 / 低點」,並提供個股查詢、成績追蹤、研究發現與方法說明。
定位是**看盤輔助**:判斷當提醒,不當買賣指令,網頁不放回測與報酬。
目前是展示版(畫面上有標示),只給自己或研究團隊用,不公開、不收費。

2026-11-22 使用者決定(專題發表 Demo):判斷方法改成和 `final` 分支相同 —— 規則挑候選 → 高點、低點各一組 AE(29 → 16)+ OC-SVM。
這個分支已 merge `final`,研究程式與結果檔(`method_kline_peak/` 底下 `web/` 以外)和 `final` 完全相同;網頁系統只多了 `web/`。
模型用 TW200 剔除低波動股(168 檔)訓練;推薦範圍是台灣 50。

## 快速開始

```bash
pip install -r requirements.txt                      # 專題根目錄的套件清單(torch、scikit-learn、yfinance、pyarrow…)
python method_kline_peak/web/run.py replay --start 2026-01-01   # 第一次:回放上線前的日子,成績追蹤才有歷史
python method_kline_peak/web/run.py start            # 每日批次 + 開本機網頁 http://localhost:8000
```

之後每天 18:00 以後跑一次 `run.py daily` 就好,網頁用 `run.py serve` 開。

| 指令 | 做什麼 |
|---|---|
| `run.py daily` | 每日批次:更新 K 線 → 判斷並存檔 → 對答案 → 產生網頁資料 |
| `run.py daily --offline` | 不連網,只用已快取的 K 線(判斷基準日 = 快取的最後一天) |
| `run.py update` | 只下載 K 線(ETF 代號確認、還原價、畫面用的未還原價),不判斷 |
| `run.py daily --date 2026-09-10` | 指定判斷基準日(補跑);那天已經有存檔就不重算 |
| `run.py replay --start 2026-01-01 [--end …]` | 逐日產生回放存檔(已存在的日子跳過);已有存檔但計算範圍後來加了股票的日子,只補算新加的股票(`days_extra/`) |
| `run.py train --year 2027` | 手動重訓某一年的模型(平常不用,批次會自動處理) |
| `run.py publish` | 只重新產生網頁資料 |
| `run.py serve [--port 8000]` | 開本機網頁(只聽 127.0.0.1) |
| `--universe tw200` | 只算研究用 TW200 清單裡的上市股(預設 `all` = 全部上市、上櫃普通股與 ETF,約 2,200 檔,供個股查詢) |
| `--pool tw100` | 換訓練用股票池(預設 `tw200`;可用 `data_loader.TICKER_SETS` 的名稱),一樣剔除低波動股(final 只有 TW200 的結果檔,其他股票池照 mainline 的規則算) |
| `--train-min-amp 3` | 換訓練門檻(%,預設 0;同研究的 `--train-min-amp`,對答案仍用原本的標籤) |

### 換股票池、推薦範圍或訓練門檻

都是設定值,不用改程式:命令列參數,或環境變數 `KPWEB_POOL`(訓練用股票池)、`KPWEB_RECOMMEND`(推薦範圍,預設 `tw50`)、`KPWEB_TRAIN_MIN_AMP`。

- 每組設定的模型、判斷存檔、答案分開放在 `data/<設定>/`(例 `data/tw200/`、`data/tw200_amp3/`),互不覆蓋;K 線快取共用 `data/prices/`。
- TW200 在 2026 年(含)以前的訓練股票池直接用研究結果檔記錄的清單(`results/backtest_long_only_tw200.json`,168 檔),和研究完全相同、同順序;
  2027 年起(或其他股票池)照 `mainline.load_data` 的規則用前一年底的資料剔除低波動股。
- 換設定後網頁顯示的是最後一次執行的設定(`site/data/` 會整批重寫)。

### 每天自動跑

- macOS / Linux(crontab,週一到週五 18:10):
  `10 18 * * 1-5 cd /path/to/fcukproject && python method_kline_peak/web/run.py daily >> method_kline_peak/web/data/daily.log 2>&1`
  資料晚到時可以在 20:10、22:10 各加一行;已經存檔的日子不會重算。
- Windows(工作排程器):動作設為 `python method_kline_peak\web\run.py daily`,起始位置設為專題根目錄。

## 運作方式

| 項目 | 做法 |
|---|---|
| 模型 | 和 `final` 相同:`walkforward.MainlineSource`,直接用研究的類別。規則候選(t 收盤是最近 6 天最高 → 高點候選、最低 → 低點候選)→ 高點、低點各一組 AE(29 → 16)+ OC-SVM(只學真的高 / 低點),候選落在 OC-SVM 範圍內(分數 > 0)才判高 / 低點。Y 年用 Y−4 ~ Y−1 訓練,訓練期最後 5 個交易日剔除;種子 42、標籤門檻 0%。2026 年(含)以前的模型用研究快取 `common/cache/yf_2026` 的 K 線訓練(和 `final` 同一份資料),2027 年起用網頁自己的 K 線快取 |
| 輸出 | 每檔每天:判斷(高點 / 低點 / 非極值)、規則候選(高 / 低 / 不是候選)、分數(OC-SVM 的 decision 值,只有候選才有)。沒有機率;分數只用來排序 |
| 信心等級 | 拿掉了。分數在訓練期同類判斷裡切三分位(高 / 中 / 低),用回放資料檢查各等級的命中率沒有差別(見下方「信心等級的檢查」),所以畫面不顯示、存檔也不存 |
| 訓練股票池 | 研究版 TW200 剔除低波動股(和研究 `--pool tw200` 同一份) |
| 推薦範圍 | 台灣 50 全部 50 檔,每天都給判斷(低波動股也照樣判斷);今日判斷、成績追蹤只看這 50 檔 |
| 計算範圍(個股查詢) | 上市(.TW)、上櫃(.TWO)普通股與 ETF 全部用同一個模型判斷;ETF 的 Yahoo 代號第一次下載時 .TW / .TWO 都試,記在 `data/tickers.json`。興櫃不計算(顯示「資料不足」),Yahoo 沒有資料的也顯示「資料不足」;特別股、存託憑證不支援 |
| 重訓 | 每年自動:1 月第 6 個交易日之後第一次跑批次時訓練新的一年(約 1 分鐘),在那之前沿用前一年的模型 |
| 資料 | 模型用 yfinance 還原價,快取在 `data/prices/`;第一次從研究快取 `common/cache/yf_2026` 複製(研究快取不會被改)。只下載最後一天之後的資料,重疊區間收盤差 > 0.2%(除權息)就重抓整段 |
| 畫面上的價格 | 收盤、K 線、量用 Yahoo 未還原價(`data/prices_raw/`,2025 年起;已用證交所官方日資料抽查,中華電 2026 年收盤留在 `tests/fixtures/` 當測試);抓不到的股票才用還原價,畫面標「還原價」。漲跌幅用還原價算,除權息當天和看盤軟體一樣對參考價。只影響顯示,判斷與對答案一律用還原價(和研究一致)。Yahoo 的價格已照股票分割比例換算 |
| 每日判斷 | 計算範圍全部都算(個股查詢用);推薦清單只列台灣 50,判低點 / 判高點依「沒破底 / 沒創高」天數分組、組內依分數排序;成績追蹤的「前 3 檔」= 每天分數最高的 3 檔 |
| 存檔 | `data/<設定>/days/<日期>.json` 當天判斷(`judge`:pred、cand、score)、`data/<設定>/grades/<日期>.json` 5 天後的答案;計算範圍後來加的股票補算在 `days_extra/`、`grades_extra/`。全部都是寫過就不再改。真實輸出的節錄在 `samples/` |
| 對答案 | t+5 收盤後,用研究的同一個標籤規則判斷是不是真高 / 低點 |
| 股票分類 | 台灣 50(推薦範圍)/ 池外(上市、上櫃、ETF,提示推薦範圍外)/ 低波動(推薦範圍以外、每日漲跌幅中位數 < 0.725%,顯示不適用)/ 資料不足(興櫃、Yahoo 沒資料、K 線太少)/ 不支援(特別股、存託憑證)/ 今日無交易 |
| 研究結果 | 網頁上的研究數字直接讀 `final` 的結果檔(`results/confusion_2024_2026_tw200.json`、`per_stock_mainline_2024_2026.json`、`backtest_strategies_2024_2025.json`),不重算;研究發現頁不放報酬表,只寫一句「扣成本後全部虧損」 |
| 前端 | `site/` 靜態網頁,讀 `site/data/*.json`(每次批次重寫) |

`data/` 與 `site/data/` 不進 git。每日存檔是唯一的紀錄,換電腦時要一起搬。

## 頁面

| 頁面 | 網址 | 內容 |
|---|---|---|
| 今日判斷 | `#today` | 台灣 50 判低點 / 判高點,依「沒破底 / 沒創高」天數分三組(剛出現、1–2 天、3 天以上);每檔只列代號、名稱、走勢小圖、分數,已幾天沒破底、連續 2 天以上才加標記 |
| 個股查詢 | `#stock`、`#stock-2454` | 今天的判斷、是否為規則候選、分數、今年判低點 / 判高點的天數、對幾天、命中率、最近 5 天內還沒破底 / 沒創高的訊號、今年整年的 K 線(可放大後左右捲動)與每天的判斷對錯;台灣 50 以外的股票加提示 |
| 成績追蹤 | `#track` | 台灣 50 每天的判斷 5 天後對答案:命中率、前 3 檔(分數最高)、推薦範圍以外的命中率、每日明細 |
| 研究發現 | `#findings` | `final` 的結論:真高低點大多抓得到(三年找到率約 7–9 成)、高低點不判反、命中率約三成、多判的訊號很多 → 看盤輔助、不是交易訊號(扣成本後全部虧損,一句話帶過);「怎麼用」 |
| 方法與說明 | `#about` | 標籤定義、判斷三步驟(規則候選 → 29 個數字 → AE + OC-SVM)、研究命中率、免責聲明 |

- 判斷基準日顯示在頁首;判斷基準日比今天舊超過 4 天時,頁面頂端會提示「資料只到 …,不是最新股價」。
- 版面只放數字、圖和 2–6 字的標籤;說明文字放在提示框(滑鼠移上或點一下卡片)或「展開看更多」裡,頁首只顯示判斷基準日。
- 「連續第 N 天」「已 M 天沒破底」只用當天以前的存檔與價格(`system/signals.py`),產生網頁資料時才算。

## 發布成 claude.ai Artifact

```bash
python method_kline_peak/web/run.py publish          # 產生 site/data/
python method_kline_peak/web/build_artifact.py       # 打包成 dist/(index.html 只放頁面內容,其餘檔案原樣複製)
```

`dist/index.html` 加上 `dist/` 裡的其他檔案發布成一個 Artifact。個股資料依代號前兩碼分檔(`stocks/23.json`;ETF 用前四碼,例 `stocks/0087.json`),
點了才載入;Artifact 一次最多發布 255 個檔案、一個版本最多 511 個,所以不能一檔股票一個檔。頁面支援淺色 / 深色主題與手機版面。

台灣 50 / 池外 / 低波動 / 不支援判定、判斷檔格式(判斷、規則候選、分數;判高 / 低點一定是候選且分數 > 0)、股票池與訓練門檻設定、連續天數與沒破底天數(不偷看未來)、
研究發現的數字和結果檔一致、網頁資料沒有回測與報酬欄位、特徵不偷看未來、每日批次與回放結果相同、正式模型重現研究 TW200 2026 年的成績。
