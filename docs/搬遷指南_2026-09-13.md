# 搬到另一台電腦(2026-09-13)

總量約 32 GB,其中 **必要的只有 2 到 3 GB**,其餘是可重算的中間產物。

## 一、什麼要搬、什麼不用

| 類別 | 內容 | 大小 | 搬法 |
|---|---|---|---|
| **程式與設定(必要)** | `common/paths.py, README.md`、`method_xgb/src, config, tests, *.md`、`method_kline/`、`method_kline_v2/`、`method_chartgcn/core, analysis, *.py, *.md`、`method_tomt/port`、`backtest/ncku/*.py, backtest/(框架), scripts, report`、`docs/`、`requirements.txt`、`.gitignore` | < 100 MB | git 或直接複製 |
| **原始資料快取(必要,重抓要幾小時)** | `common/cache/yf`(494 MB)、`yf_2026`(86 MB)、`official`(4.6 MB,證交所要抓 2 小時)、`yf_hist`、`yf_fw`、`kline_raw`、`finmind`、`finmind_2026`(籌碼要 token 和額度) | 約 800 MB | 複製 |
| **實驗結果(必要,重算要一天)** | `method_xgb/experiments/*.json, *_testpred.parquet, *_importance.csv`、`backtest/results/`(17 MB)、`backtest/ncku/out/*.json`(xlsx 可略)、`method_kline_v2/results/`、`method_chartgcn/experiments_2026/*.json` | 約 1 GB | 複製 |
| 可重算的中間產物(選) | `common/cache/features`(4 GB,`run_pipeline.py` 自動重建,tw200 約 10 分鐘)、`common/cache/bigmove`(3.2 GB,`build_dataset.py` 約 15 分鐘)、`method_xgb/experiments` 其餘(lowmem memmap、diag) | 約 14 GB | 有硬碟就一起搬,省時間 |
| 不搬 | `_archive/`(Qlib venv 等)、`method_chartgcn/experiments_paper`(9.8 GB 論文復現模型,已收尾)、`__pycache__` | 10 GB+ | 留在舊機或另外備份 |

## 二、步驟

1. **舊機**:先把 git 收乾淨
   - `method_chartgcn` 有 136 個未提交檔,`method_kline` 有 `kline/supervised_model.py` 未提交:各自 commit + push 到 `github.com/lintaixu/fcukproject`(兩個資料夾是同一個 repo 的 `Chart-GCN` / `main` 分支)。
   - 專題根目錄目前不是 git:建議 `git init`,用剛寫好的 `.gitignore`(排除 cache / 大檔),把 `common`、`method_xgb`、`method_kline_v2`、`backtest`、`docs`、`scripts` 收進去並 push 到新的私人 repo。之後兩台機器用 git 同步程式,只有資料用硬碟。
2. **舊機**:打包資料
   `powershell -File scripts\pack_for_migration.ps1 -Dest "E:\專題進度"`(必要項,約 2 GB)
   加 `-WithRegenerable` 連特徵面板與 bigmove 一起(約 16 GB)。
3. **新機**:
   - 安裝 Python 3.12(舊機 3.12.3),`pip install -r requirements.txt`(torch 是 CPU 版 2.11.0;新機有 GPU 可另裝 CUDA 版)。
   - 把 `E:\專題進度` 放到 `C:\Users\<帳號>\Desktop\專題進度`(路徑可以不同,`common/paths.py` 全部用相對路徑)。
   - `method_tomt/Qmodel` 用 `git clone https://github.com/TomweiLu/Qmodel.git` 取回(唯讀參考,不用搬)。
   - 設環境變數 `FINMIND_TOKEN`(token 不在任何檔案裡,要自己貼)。
   - 記憶體:舊機 pagefile 固定 512 MB 常撞 MemoryError;新機讓 Windows 自動管理 pagefile,跑 tw500 / all 才不會掛。
4. **新機驗證**(各 1 分鐘):
   - `python backtest/scripts/compare_vf_v3_acc.py`(讀 experiments + results)
   - `cd backtest/ncku && set NCKU_SRC=official && python run_vf_v3.py --years 2026`(成大框架 + 官方資料,應得 v3 +230.3%)
   - `python method_kline_v2/check_separability.py --pools tw50 --sets C`(讀 bigmove;沒搬的話先 `build_dataset.py --pool tw50`)
5. **Claude 記憶**:`%USERPROFILE%\.claude\projects\c--Users-alex-Desktop-----\memory\`(打包腳本會複製到 `_claude_memory`)。新機路徑相同就放回同名資料夾;路徑不同時,資料夾名是專題路徑的編碼(`C:\Users\alex\Desktop\專題進度` → `c--Users-alex-Desktop-----`),照新路徑改名。

## 三、之後兩台機器怎麼同步

- 程式:git(根目錄 repo + fcukproject repo)。
- 資料快取:只會往後增加(新一天的 official / yf_2026),用 `fetch_official.py`、`update_official.py` 在哪台跑就在哪台更新,或定期 robocopy `common/cache` 的幾個小資料夾。
- 實驗結果:`method_xgb/experiments/*.json`、`backtest/results`、`*/results` 都是小檔,可以進 git(`.gitignore` 只排除 parquet 與 memmap)。
