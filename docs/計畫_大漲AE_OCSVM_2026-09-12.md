# 計畫:大漲股票集 → Autoencoder → One-Class SVM(2026-09-12 草案)

## 0. 架構(使用者提出)

```
收集「之後會大漲」的股票日 ──▶ 只用這些樣本訓練 AE
                                    │
                        驗收:輸入 → 潛在 → 輸出 能還原(重建誤差夠小、驗證段不劣化)
                                    │
                        用 AE 的潛在向量訓練 OC-SVM(只餵大漲樣本)
                                    │
               新樣本:潛在向量落在 OC-SVM 的範圍內 = 「像會大漲」 → 買進候選
```

評估一律用 Precision / Recall / Accuracy / F1(對照:隨機挑的 Precision = 正例比例),不看回測報酬,除非另外要求。

## 1. 這個架構成立的前提(先講清楚,後面每一步都在驗這件事)

One-Class 學習只在一種情況下有效:**正例(會大漲的樣本)在輸入空間裡自成一群,跟其他樣本長得不一樣**。
AE 只負責壓縮,不會「創造」分離度;輸入裡分不開的,潛在空間也分不開。

目前已知的證據(K 線 7 特徵、5 日 ±5%):
- 大漲樣本 vs 大跌樣本可分性 AUC 0.558(原始)/ 0.554(AE 4 維)→ 幾乎同一群。
- AE 只用大漲樣本訓練,重建誤差反而是「其他樣本」最小(它們比較平淡、好重建),AUC 0.34 ~ 0.45,低於 0.5。
- OC-SVM 對大漲、大跌樣本各接受 93% 與 94%。

所以這個計畫的核心不是「把 AE + OC-SVM 接起來」,而是**找到一種資料收法,讓大漲樣本真的自成一群**。
每個階段設「過關條件」,沒過就不往下做,回頭改資料。

## 2. 階段一:資料怎麼收

### 2.1 「大漲」的定義(要決定一個)

正例數量(2016 ~ 2026-09,實際資料算出來):

| 定義 | tw50 每年正例 | tw200 每年正例 | 佔比 |
|---|---|---|---|
| 5 日 > +5%(現行) | 1,058 | 5,925 | 8.7% / 11.3% |
| 5 日 > +8% | 456 | 2,887 | 3.8% / 5.5% |
| 5 日 > +10% | 283 | 1,886 | 2.3% / 3.6% |
| 20 日 > +15% | 655 | 3,984 | 5.4% / 7.6% |
| 20 日 > +20% | 364 | 2,376 | 3.0% / 4.6% |
| 20 日 > +30% | 146 | 1,007 | 1.2% / 1.9% |

建議:
- **門檻用波動度縮放**(三重障礙法):上牆 = k × 該股近 20 日日波動 × √天數,而不是固定 %。台積電漲 5% 和小型電子股漲 5% 不是同一件事。固定 % 會讓正例集中在高波動股,AE 學到的是「高波動股長什麼樣」,不是「要漲之前長什麼樣」。
- **持有天數 5 或 10 天**;20 天太長,K 線型態的資訊撐不到。
- 正例佔比目標 **3 ~ 5%**:太多(8% 以上)就跟一般樣本混在一起,太少 AE 沒東西學。
- 股票池用 **tw200**:tw50 一年只有 300 ~ 1,000 個正例,不夠;tw200 有 2,000 ~ 6,000。

### 2.2 要排除的樣本

- 除權息日前後 5 天(KLINE 已做)。
- (漲停樣本**不排除**,使用者 2026-09-12 決定;之後若要處理「訊號日漲停買不到」,在回測端用 Logic2 的 `limit_aware` 處理,不動訓練資料。)
- 停牌、成交量為 0 的日子。
- 5 日均量 < 2,000 張(跟 v3 一致,之後才接得上交易)。

### 2.3 輸入(這是最關鍵的決定)

三個候選,**都要做 2.4 的可分性檢查**再選:

| 方案 | 內容 | 維度 | 說明 |
|---|---|---|---|
| A | 現行 K 線 1 ~ 3 日特徵 | 7 ~ 12 | 已知分不開(AUC 0.56),當對照組 |
| B | 最近 20 天 OHLCV,每天以當天收盤正規化,量用對 60 日均量的比 | 100 | 才有「型態」可言;初步測試也分不開,但可再試不同正規化 |
| C | 20 天視窗 + 240 個技術指標(method_xgb 現成) | 340 | 資訊最多;XGB 用這些能到 AUC 0.56 ~ 0.57,是目前上限 |

加上兩個所有方案都要有的欄位:**相對大盤的報酬**(扣掉 0050 同期)、**相對同池的排名**。大漲有一半是大盤帶的,不扣掉的話 AE 學到的是大盤。

### 2.4 收完先做的檢查(過關條件)

在動 AE 之前,先用最簡單的方法看資料有沒有訊號:

1. **可分性**:logistic 回歸分「正例 vs 其他」,時間切分,驗證 AUC。
   - AUC < 0.55:這組輸入沒有可用的資訊,AE 和 OC-SVM 都救不了 → 換輸入或換定義。
   - AUC ≥ 0.60:才值得往下做。
2. **正例是不是一群**:對正例做 k-means(k = 3 ~ 5),看每群的中心跟「其他樣本」的距離,再看正例到最近正例的距離 vs 到最近非正例的距離(kNN 純度)。
   - 純度接近正例比例(例如 10% 的正例,鄰居裡也只有 10% 是正例)→ 沒有自成一群,One-Class 不會有用。
   - 純度明顯高於比例(例如 25% 以上)→ 有群,One-Class 有機會。

這一步大約半天,決定整個計畫要不要走下去。

### 2.5 切分

- 時間順序:訓練 2016 ~ 2022、驗證 2023 ~ 2024、測試 2025 ~ 2026-09;訓練與驗證交界去掉持有天數(purge)。
- 逐年 walk-forward 留到最後,先把單一切分做通。
- 正例的**訓練集**只用訓練期的正例;驗證與測試都是全部樣本(正例 + 非正例),因為上線時模型要面對的是全部。

### 2.6 存放

- `common/cache/bigmove/`:`samples_<pool>_<label定義>.parquet`(index = date, ticker;欄 = 輸入特徵 + future_ret + label + 排除旗標)。
- 產生腳本放 `method_kline_v2/build_dataset.py`(讀 `common/paths`,不動 `method_kline/`)。

## 3. 階段二:AE 訓練與「可還原」驗收

### 3.1 結構

- 輸入維度依 2.3;隱藏層 2 層;潛在維度從 **8、16、32** 三種試(4 太小,64 對 7 維輸入等於沒壓縮)。
- 損失:MSE;訓練 60 ~ 200 epoch,驗證段重建誤差不再下降就停。
- 只用訓練期的正例訓練。

### 3.2 過關條件(「有學起來」的定義)

| 檢查 | 標準 |
|---|---|
| 訓練 / 驗證重建誤差 | 驗證誤差 ≤ 訓練誤差 × 1.3(沒過擬合);相對於「輸出全部猜平均值」的誤差要降到 30% 以下 |
| 每個輸入欄位的還原 | 逐欄看重建的相關係數,不能有某些欄位完全還原不了(代表潛在維度太小) |
| **正例 vs 非正例的重建誤差** | 這是關鍵:只用正例訓練後,**非正例的重建誤差要明顯大於正例**(AUC ≥ 0.60)。如果非正例反而更好還原(目前 K 線 7 特徵的情況),代表正例沒有獨特結構,One-Class 不會成立 |
| 潛在空間 | 用 logistic 在潛在向量上分正例 vs 其他,AUC 不能比原始輸入低超過 0.02(壓縮沒弄丟資訊) |

第三條沒過 → 停,回階段一。

## 4. 階段三:One-Class SVM

- 輸入:AE 潛在向量(訓練期正例)。
- 參數:nu 從 0.05、0.1、0.2、0.5 掃;gamma = scale 與幾個固定值。
- 另外做一個**不用 OC-SVM 的對照**:直接用 AE 重建誤差當分數(誤差小 = 像正例),取前 k%。這是 AE 異常偵測的標準做法,比 OC-SVM 少一層。

### 4.1 評估(驗證段與測試段都算)

| 指標 | 對照 |
|---|---|
| Precision(判「像」的裡面真的大漲) | 隨機 = 正例比例(3 ~ 5%);**目標 ≥ 2 倍隨機** |
| Recall | 記錄,不當目標 |
| Accuracy | 附上「全猜否」的值,說明它對稀有事件不敏感 |
| F1 | |
| 出訊號比例 | 必須控制在 5 ~ 15%,不然 Precision 沒意義(現在是 97%) |
| Precision@K | 最像的前 5% / 10% |

### 4.2 額外對照組(一定要有,不然不知道 One-Class 有沒有貢獻)

- 同一個 AE 潛在向量 + **有反例的分類器**(logistic / XGB),同樣輸出前 10%。
- 原始輸入 + XGB,不經過 AE。
- 如果 One-Class 的 Precision 沒有贏過這兩個,結論就是「AE 可以留,OC-SVM 換掉」。

## 6. 已決定(2026-09-12)

- 大漲定義:**5 日固定持有,上牆 = 2 × σ20 × √5**(σ20 = 近 20 日日報酬標準差),先不設下牆;跑通後再加下牆(先跌到 −1σ 記 0)比 Precision。
- 先確認模型準確率,再考慮持有天數的其他方案。
- 股票池三種都做:**tw50、tw200、elec_all(全電子股)**。
- 漲停樣本不排除。
- 輸入 A / B / C 都做階段一檢查再選(elec_all 沒有現成 240 指標面板,C 暫缺)。

實際正例(流動性 ≥ 2,000 張、去 NaN 後):tw50 110,987 列 / 正例 4.75%(每年 330 ~ 630);tw200 329,126 列 / 5.07%(每年 900 ~ 1,900);elec_all 359,956 列 / 5.01%(每年 740 ~ 2,450)。資料在 `common/cache/bigmove/samples_<pool>.parquet`,程式 `method_kline_v2/build_dataset.py`、`check_separability.py`。
