## 結論
- 六組走動 AUC 相差最多 0.0075,除「深度 7 × lr 0.03」略差外,其餘五組相差 ≤ 0.003,與 seed 波動同量級;年份之間的差(0.52 → 0.56)遠大於參數之間的差。
- 走動式略偏好深度 3,2026 測試卻是深度 3 最低,方向相反,皆在誤差(SE ≈ 0.006)內 → 沒有理由更動深度。
- lr 0.01 在每個深度的走動 AUC 都 ≥ lr 0.03,seed 波動也較小,但訓練時間約 3 倍,增益 ≤ 0.002(深度 5)。
- 2023、2024 兩折早停在 3~98 棵,2025 折 70~899 棵:早停年(2022、2023)幾乎沒有可學的訊號。
- 維持現用 max_depth 5、lr 0.03。
