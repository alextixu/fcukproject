# repo 的 `TW50_TICKERS` 不是任何一天的官方成分股:出處與受影響的結果(2026-09-21)

## 一、怎麼發現的
做股票池修正(公告重建臺灣 50 逐日成分股)時,原計畫從 repo 的名單往回推。先用維基百科的變動表當索引試推,**沒有任何一個時點能讓名單與變動表吻合**(最好的錨點仍有 47 個矛盾),於是回頭查名單的出處。

## 二、出處(git)
| commit | 日期 | 內容 |
|---|---|---|
| d071480 | 2026-05-06 | 初次上傳。`TW50_TICKERS` 只有 15 檔,註解寫「台灣 50 ETF **主要成分股(簡化清單,實際可擴增)**」 |
| dbe276e | 2026-05-28 | 擴成 50 檔,註解改成「台灣 50 ETF 成分股(**完整清單**)」。commit 訊息是 Grid Search 與模型改進,**沒有提到名單的來源或日期** |
| 90ccce2、fa32dcd、033e442 | 2026-06-04 ~ 09-13 | 只有搬檔案,名單內容沒有再變過 |

結論:名單是 2026-05-28 手動補齊的,沒有日期、沒有出處;之後四個月所有「tw50 / 台灣 50」實驗都用它。

## 三、它和官方成分股差多少
依臺灣指數公司 45 份定期審核通知 + 非定期通知整理出的官方增刪事件(`common/universe/tw50_official_events.csv`,49 個事件、自身無矛盾),比對各時點「由事件可確定的成員狀態」:

| 時點 | repo 名單裡當時**確定不是**成分股的 | 當時**確定是**成分股但 repo 沒有的 |
|---|---|---|
| 2016-01-04 | 11 檔 | 12 檔 |
| 2019-01-02 | 9 檔 | 10 檔 |
| 2022-01-03 | 7 檔 | 8 檔 |
| 2025-01-02 | 7 檔 | 8 檔 |
| 2026-05-28(名單建立日) | 15 檔 | 16 檔 |
| 2026-09-21 | 17 檔 | 18 檔 |

同一份名單裡同時有 2021-06 才納入的長榮 2603、陽明 2609、萬海 2615,以及同一天被刪除的正新 2105、可成 2474、台灣高鐵 2633 → **不可能是任何單一日期的快照**。另有聯強 2347(依索引 2013 年已剔除)。
它比較像「2021 ~ 2025 年間不同時點成分股的混合」;和任何一天的官方名單至少差 7 ~ 8 檔(約 15%),在名單建立當天差 15 ~ 16 檔(約 30%)。

## 四、受影響的結果(股票池描述都要更正為「來源不明的 50 檔大型股」)
凡是 pool = tw50 的結果全部受影響;tw100 / tw200 / tw300 / tw500 是巢狀池(前 50 檔就是這份名單),它們不宣稱是指數成分股,但「台灣 50 → 中型 100」這種說法也要改。

| 類別 | 文件 / 產物 |
|---|---|
| Chart-GCN(05 ~ 08 月與 v1.0 ~ v1.7) | docs 2026-05-07、05-28、07-05、07-21、07-26、08-10、08-20、08-23 各份;`method_chartgcn/實驗記錄_2026.md`、`實驗記錄_v1.md`、`版本記錄.md`、`融合實驗報告.md`、README;架構圖網頁(artifact WvZ25Uwj…)裡所有「台灣 50」字樣 |
| XGBoost / A 系統 | docs 2026-09-14 三份(四系統比較、統一協定、tw500 h20 收尾)、09-15 四份(提案 2、報告用 prompt、50 點回覆、逐年走動)、09-20 三份(漏斗篩選、深度網格、每日選股頁);`method_xgb/實驗記錄.md`、`計畫書.md`、README;`method_xgb/experiments/` 裡 116 個 tw50 結果檔;AE + XGBoost 流程圖網頁(artifact 6j4hxsYT…)、每日選股推薦頁(artifact LFPFq5q6…) |

| 09-21 的診斷 | 第 1 步時段拆解與事後探索 A ~ E(已標為初步 / 暫定) |
| 文獻對照 | docs 2026-09-20 文獻摘要裡描述本研究設定的段落 |

對第 1 步趨勢類結果的解讀也要改:原本的理由是「名單由現在還在的贏家組成,趨勢訊號很可能被放大」;但這份名單混了早已被剔除的股票,**偏差的方向與大小都無法判斷**。結果仍是暫定,理由改為「股票池定義不明」。
