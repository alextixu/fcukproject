## 一、逐年 walk-forward(測試年 Y:訓練 ≤ Y−2、早停 Y−1、特徵用 Y−1 驗證集篩;AE 訓練 ≤ Y−3、早停 Y−2、全樣本)

| 測試年 | 特徵欄 | 95 欄 Acc / AUC / 前 3 名命中 | +AE Acc / AUC / 前 3 名命中 | AE 誤差 訓練 → 測試年 |
|---|---|---|---|---|
| 2021 | 87 | 53.13 / 0.543 / 56.1% | 53.19 / 0.543 / 56.7% | 0.156 → 0.224 |
| 2022 | 98 | 50.62 / 0.506 / 50.7% | 50.49 / 0.508 / 53.3% | 0.142 → 0.171 |
| 2023 | 71 | 51.60 / 0.522 / 52.3% | 51.88 / 0.522 / 49.9% | 0.133 → 0.125 |
| 2024 | 72 | 54.16 / 0.553 / 54.0% | **54.70** / 0.559 / 54.7% | 0.133 → 0.143 |
| 2025 | 90 | 52.23 / 0.536 / 54.0% | 52.34 / 0.537 / 55.8% | 0.140 → 0.178 |
| 2026 | 95 | 51.63 / 0.528 / 60.9% | 51.82 / 0.529 / 58.5% | 0.141 → **0.259** |

- 六年裡 +AE 的 Acc 五年略高(+0.06~+0.54 pp)、一年略低(2022 −0.13),平均 +0.19 pp;AUC 差 ≤ 0.006。**AE 的增益在六年裡都在雜訊等級,但方向一致偏正。**
- 分類能力隨年份變動:2024 最好(54.2~54.7%),2022 空頭年幾乎等於隨機(50.5~50.6%)。
- Autoencoder 還原誤差:2026 測試年 0.259 是訓練期 0.141 的 1.8 倍,其他年份 0.9~1.4 倍;**2026 的指標分布明顯偏離訓練期**(回應第 6 點)。
