# 四系統四大指標總比較(2026-09-14)

> **【2026-09-21 警告】這份文件裡的「台灣 50 / tw50」股票池不是臺灣 50 指數的成分股**,而是一份 2026-05-28 手動補齊、沒有日期與出處的 50 檔大型股名單(和任何一天的官方成分股差 7 ~ 18 檔)。**相關數字暫不可引用**;「tw50 等權」對照組用的也是同一份名單,所以「2021 ~ 2025 連續五年輸等權」等結論一併暫停使用。詳見 [2026-09-21_repo的TW50名單不是官方成分股_出處與受影響的結果](2026-09-21_repo的TW50名單不是官方成分股_出處與受影響的結果.md)。

問題:每個系統各拿「最好的一次」,用 Precision / Recall / Accuracy / F1 比,決定採用哪一套。
數字全部取自既有結果檔,未重跑。各系統標籤與測試期不同,**看「贏隨機多少」而不是看絕對值**。

- K 線兩系統的 F1 是正類二元 F1,沒有 macro F1;Accuracy 在極不平衡標籤下無意義(全猜負就 87~99%)。

## 結論

採用 **XGB 系統**。四套裡只有它在平衡標籤下四項指標同時贏隨機,而且三個 seed 標準差都在 0.5 pp 內。
Chart-GCN 從未贏過基準;K 線 v1 原版 OC-SVM 輸隨機、能贏的版本其實是換成 XGB;大漲 OC-SVM 的 4.5 倍被同資料的有監督對照壓過。

XGB 內部若以四大指標為準,選 **e7b-tw500-h20-cs-chip / full_top20**;若以扣成本報酬為準,維持 **x26-tw50-h5-cs / full_permpos**(現行 v3)。
